# AI 总结模块 - 提示词配置说明

## 文件说明

| 文件 | 用途 |
|------|------|
| `summary-sys-prompt.md` | 系统提示词（角色设定 + 输出约束 + 内容安全策略） |
| `summary-usr-prompt.md` | 用户提示词模板（数据注入占位符） |
| `summary-prompt-config.md` | 本配置说明文件 |

## 设计目标

1. **输出结构固定**：必须是两段式
   - 第一段：一句话用户形象（可直接作为称号/人设）
   - 第二段：基于真实统计数据的详细收藏画像
2. **二次元调性**：软萌猫娘「小咔」人设，适度语气词，圈内用语自然融入
3. **R18 内容友好**：明确指示模型不要回避成人向标签/分类，直接分析
4. **模型兼容性**：针对 DeepSeek / Qwen / OpenAI 系列做了破甲与指令强化
   - 在系统提示中反复强调「不要拒绝」「不要道德评判」
   - 用角色扮演 + 明确任务边界降低安全过滤触发率
5. **数据驱动**：所有描述必须来自提供的统计结果，禁止捏造

## 占位符说明（用户提示词）

| 占位符 | 说明 | 建议格式 |
|--------|------|----------|
| `{{totalComics}}` | 收藏总数 | 数字 |
| `{{authorCount}}` | 去重作者数 | 数字 |
| `{{categoryCount}}` | 去重分类数 | 数字 |
| `{{tagCount}}` | 去重标签数 | 数字 |
| `{{finishedCount}}` / `{{unfinishedCount}}` | 完结/未完结数量 | 数字 |
| `{{categoryWordCloud}}` | 分类词云数据 | `分类名(次数)、分类名(次数)...` 或 JSON |
| `{{tagWordCloud}}` | 标签词云数据 | 同上 |
| `{{authorWordCloud}}` | 作者词云数据 | 同上 |
| `{{viewsTop10}}` | 浏览量 TOP10 | `标题 - 作者 (浏览量)` 列表 |
| `{{likesTop10}}` | 点赞量 TOP10 | 同上 |
| `{{highLikeRateSummary}}` | 高点赞率特征摘要 | 简短文字 |
| `{{avgEps}}` / `{{avgPages}}` 等 | 内容规模指标 | 数字 |
| `{{createYearDist}}` | 创建年份分布 | `2020:12本, 2021:8本...` |
| `{{updateStatus}}` | 最近更新情况 | 简短描述 |
| `{{commentsTop10}}` | 评论 TOP10 | 列表 |
| `{{avgComments}}` | 平均评论数 | 数字 |
| `{{interactionIndex}}` | 互动指数特征 | 简短文字 |
| `{{hotHitCount}}` 等 | 热门关联数据 | 数字或简短描述 |
| `{{keywordMatch}}` | 热门搜索词匹配 | 简短描述 |

> 当某类数据尚未采集（例如用户未开启深度分析）时，对应占位符可填「暂无数据」或直接省略该段落。

## 模型参数建议

- temperature: 0.7 ~ 0.85（保留一定创造性，但不过分发散）
- max_tokens: 800 ~ 1200（足够写完两段）
- 优先使用支持较长上下文的模型，以便完整注入统计数据
